# 예약 및 대기 목록 조회 성능 개선

## 문서 목적

예약 공개 직후 조회 요청이 증가하는 가상 상황을 설정하고, 성능 테스트를 통해 예약 및 대기 목록 조회 API의 병목 지점을 찾는다.

병목 원인에 적합한 개선 방법을 적용한 뒤, 동일한 조건에서 성능을 다시 측정하여 개선 효과를 검증한다.

## 분석 순서

```text
가상 상황과 성능 목표 정의
→ 현재 구현의 성능 저하 재현
→ 서버 자원 및 요청 처리 구간 분석
→ 병목 원인 도출
→ 개선 방법 선택 및 구현
→ 동일 조건에서 개선 효과 검증
```
